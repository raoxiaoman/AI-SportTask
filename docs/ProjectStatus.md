# AI SportTask 项目状态文档

## 项目概述
AI SportTask 是一款个人运动任务管理与打卡应用，帮助用户以动作为单位组织训练，制定训练计划，按日打卡并进行统计分析。

## 技术栈
- **平台**: Android、iOS (Kotlin Multiplatform)
- **UI**: Compose Multiplatform
- **数据**: SQLDelight (本地持久化)

## 项目结构
```
├── shared/
│   ├── src/
│   │   ├── commonMain/
│   │   │   ├── kotlin/
│   │   │   │   ├── App.kt             # 应用主入口与导航
│   │   │   │   ├── data/             # 数据层（Repository、Model、成就系统）
│   │   │   │   ├── db/                # 数据库层
│   │   │   │   ├── pages/             # 页面组件
│   │   │   │   └── ui/                # UI 通用组件（成就弹窗等）
│   │   │   └── sqldelight/            # SQLDelight 数据库定义
│   │   ├── androidMain/
│   │   │   └── kotlin/               # Android 平台实现
│   │   └── iosMain/
│   │       └── kotlin/               # iOS 平台实现
│   └── build.gradle.kts
├── androidApp/
├── iosApp/
├── docs/                             # 需求文档与 UI 原型
└── build.gradle.kts
```

## 注意事项
- 项目采用 Kotlin Multiplatform 架构，支持 Android 和 iOS
- 使用 Compose Multiplatform 构建跨平台 UI
- 数据默认本地存储，后续将支持云同步
- 日期格式统一为 `YYYY-MM-DD`
- 时长字段单位统一为秒
