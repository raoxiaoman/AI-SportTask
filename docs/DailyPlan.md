## 每日工作流程

### 早上（任务规划）
1. 查看昨日未完成任务
2. 确认今日具体目标
3. 拉取最新代码 `git pull`

### 白天（开发实现）
1. 实现功能代码
2. 本地构建验证 `./gradlew androidApp:assembleDebug`
3. 提交代码 `git add . && git commit -m "feat: ..."`

### 晚上（代码审查）
1. 运行完整构建测试
2. 检查是否有待推送的提交
3. 规划明日任务
