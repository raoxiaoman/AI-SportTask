## 三、架构与代码质量提示

### 当前代码可改进点

1. **Repository 单例问题**：`SportTaskRepository()` 每次都创建新实例，建议改为单例或依赖注入
2. **暗色模式状态管理**：`App.kt` 的 `isDarkMode` 与 `SettingsPage.kt` 的本地 `isDarkMode` 可能不同步（SettingsPage 有自己的状态变量而非接收参数）
3. **计时器精度**：当前使用 `delay(1000L)` + `Dispatchers.Default`，频繁重组可能影响精度
4. **统计数据本地计算**：`calculateConsecutiveDays` 每次全量加载所有打卡记录，数据量大时需优化
5. **iOS 状态**：iOS main 已就位但未经过真机/模拟器验证

### 建议设计模式

```
- Repository 改为 object 单例
- ViewModel 模式管理页面状态
- 依赖注入（如 Koin）方便测试
- Compose 状态提升 + 单向数据流
```
