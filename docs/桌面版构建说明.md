# 桌面版构建说明

桌面版基于 Compose Multiplatform，与手机端共用 `shared/commonMain` 的全部 UI 与业务逻辑，
仅在 `shared/jvmMain` 补齐平台能力，`desktopApp` 是窗口入口与打包模块。

## 目录结构

- `shared/src/jvmMain/kotlin/` —— 桌面平台实现（expect/actual）：
  - `pages/DateUtil.jvm.kt` —— java.time 日期
  - `pages/ExternalLink.jvm.kt` —— Desktop.browse 打开外链
  - `pages/TrainingAudio.jvm.kt` —— 音效合成播放（语音降级静音）
  - `pages/TrainingSound.jvm.kt` —— 震动空实现
  - `db/Driver.kt` —— SQLDelight JDBC 驱动
  - `data/remote/PlatformStorage.jvm.kt` —— properties 文件持久化
  - `ui/SystemBars.jvm.kt` —— 系统栏空实现
  - `ui/PlatformBackHandler.jvm.kt` —— ESC 返回键
  - `ui/AppVersion.jvm.kt` / `main.jvm.kt` —— 版本号 / 平台名
  - `data/plan/ReminderBridge.jvm.kt` —— 通知空实现
- `desktopApp/src/jvmMain/resources/audio/` —— 由 Android 端 mp3 转出的 wav 音效（tick / chime）

> 文件名带 `.jvm` 后缀是为了避免与 `commonMain` 同名文件生成重复 JVM 类名（`XxxKt`）。

## 平台策略

| 能力 | 桌面实现 |
|---|---|
| 音效（秒针 / 提示音） | Java 原生 `Clip` 播放 wav，支持音量与变速 |
| 中文语音播报 | **静音**（`trainingAudioSteps` 强制 `voiceAllowed=false`），不依赖系统 TTS |
| 震动 / 系统栏 | 空实现（桌面无对应能力） |
| 本地存储 | `~/.sporttask/sporttask_prefs.properties` |
| 训练数据库 | `~/.sporttask/sporttask.db`（SQLite） |
| 返回键 | ESC |

## 构建命令

```bash
# 本地运行
./gradlew :desktopApp:run

# 安装包（各平台需在对应系统构建）
./gradlew :desktopApp:packageDmg   # macOS → build/compose/binaries/main/dmg/
./gradlew :desktopApp:packageMsi   # Windows
./gradlew :desktopApp:packageDeb   # Linux

# 指定版本号（默认 1.0.0；安装包要求纯数字 MAJOR.MINOR.PATCH）
./gradlew -Papp.versionName=1.0.6 :desktopApp:packageDmg
```

desktop 模块构建输出默认在 `desktopApp/build/`。若遇到"Unable to delete directory .../runtime"
（部分受限开发环境会拦截项目目录内的递归删除），可用参数把构建目录挪到系统临时区规避：

```bash
./gradlew -PdesktopBuildDir=/tmp/sporttask-desktop-build :desktopApp:packageDmg
```

正常环境与 CI 无需该参数。

## 发版说明

- 桌面安装包需在 macOS / Windows / Linux 三台机器（或 CI 的对应 runner）分别构建。
- 版本号由 `-Papp.versionName` 注入，与手机端保持一致。
- 安装包产出后上传到对应平台的 GitHub Release。
