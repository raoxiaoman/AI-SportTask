# 训练音频素材与授权

执行页的所有声音都是**打包在 App 内的本地 mp3**，运行时只做 SoundPool 预加载与播放，
**不调用系统 TTS**（避免引擎初始化卡顿、冷启动静默、机型语音包缺失）。

## 素材来源

| 文件 | 用途 | 来源 | 授权 |
| --- | --- | --- | --- |
| `tick.mp3` | 倒计时每秒木质秒针 | [sfxmint.com · metronome-ticking-01](https://sfxmint.com/dl/metronome-ticking-01.mp3) | CC0 1.0（可商用、无需署名） |
| `chime.mp3` | 开始 / 切换 / 完成的柔和铃音 | [sfxmint.com · ui-chime-46](https://sfxmint.com/dl/ui-chime-46.mp3) | CC0 1.0（可商用、无需署名） |
| `v*.mp3` | 中文倒数与阶段播报 | macOS 内置 Tingting 语音**离线预生成** | 随项目分发 |

## 重新生成

```bash
./tools/generate_training_audio.sh
```

脚本依赖 macOS（`say`）、`ffmpeg`（含 libmp3lame）与 `curl`，产物输出到
`androidApp/src/androidMain/res/raw/`。脚本会：

1. 下载两段 CC0 音效，裁出 55ms 木质敲击并做提亮 / 短淡出；
2. 用 Tingting 以 220–235 字/分预生成中文播报，裁掉前后静音、限幅、尾部留 50ms 呼吸。

> 语音只在构建期生成一次，仓库内已提交成品 mp3，CI 与日常构建**不需要**运行该脚本。
